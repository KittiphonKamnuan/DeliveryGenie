# Checkpoint 3: การอัปเดต Frontend

**วันที่:** 3 พฤศจิกายน 2025
**โปรเจค:** Delivery Genie Dashboard
**หัวข้อ:** ระบบหน้าบ้านและการช็อปสินค้า

---

## สรุปภาพรวม

Checkpoint นี้เป็นการพัฒนาระบบหน้าบ้าน (Frontend) ทั้งหมด โดยเน้นการสร้างประสบการณ์การใช้งานที่แตกต่างกันตามบทบาทของผู้ใช้ (User และ Admin) และการเชื่อมต่อกับระบบค้นหาร้าน 7-11 ที่ใกล้ที่สุด

---

## 1. ระบบเมนูและการนำทาง (Navigation)

### สิ่งที่เพิ่มเข้ามา

#### เมนูแบ่งตามสิทธิ์
- **ผู้ใช้ทั่วไป (User):**
  - เห็นเฉพาะเมนูช็อปสินค้า
  - 🛒 ช้อปสินค้า
  - 🛍️ ตะกร้าสินค้า

- **ผู้ดูแลระบบ (Admin):**
  - เข้าถึงได้ทุกเมนู
  - **Dashboard:**
    - 🌟 Priority System (ระบบจัดลำดับความสำคัญ)
    - 🚚 Driver Performance (ประสิทธิภาพคนขับ)
    - 📊 Real-time Analytics (สถิติเรียลไทม์)
    - 🗺️ Route Optimization (เส้นทางที่ดีที่สุด)
  - **Shopping:**
    - 🛒 ช้อปสินค้า
    - 🛍️ ตะกร้าสินค้า
  - **Admin:**
    - 👥 จัดการผู้ใช้
    - ⚙️ ตั้งค่าระบบ

#### แสดงข้อมูลผู้ใช้
- ชื่อผู้ใช้
- อีเมล
- ตำแหน่ง (ผู้ใช้งาน / ผู้ดูแลระบบ)
- ปุ่มออกจากระบบ

**ไฟล์:** `src/components/Navigation.tsx`

---

## 2. ระบบรักษาความปลอดภัย

### การป้องกันหน้าเว็บ (Middleware)

#### กฎการเข้าถึง
1. **หน้าสาธารณะ:** ดูสินค้าได้โดยไม่ต้องล็อกอิน
2. **หน้าที่ต้องล็อกอิน:**
   - หน้า Checkout
   - หน้าสำเร็จการสั่งซื้อ

3. **สิทธิ์ตามบทบาท:**
   - **User:** เข้าได้เฉพาะหน้าช็อปสินค้า ถ้าพยายามเข้า Dashboard จะถูกส่งกลับไปหน้าช็อป
   - **Admin:** เข้าได้ทุกหน้า

4. **การ Redirect อัตโนมัติ:**
   - User ล็อกอินเสร็จ → ไปหน้าช็อป
   - Admin ล็อกอินเสร็จ → ไปหน้า Dashboard

**ไฟล์:** `src/middleware.ts`

## 3. ระบบช็อปสินค้า

### 3.1 หน้าช็อปสินค้าหลัก

#### ฟีเจอร์สำคัญ

**🔍 ค้นหาร้านที่ใกล้ที่สุดก่อน**
- เมื่อเปิดหน้าจะขอตำแหน่งปัจจุบันของผู้ใช้
- ระบบหาร้าน 7-11 ที่ใกล้ที่สุดภายในรัศมี 5 กม.
- แสดงข้อมูลร้าน:
  - ชื่อร้าน
  - ที่อยู่
  - ระยะทาง (กม.)
  - เวลาโดยประมาณ (นาที)

**📦 แสดงสินค้าเฉพาะของร้านนั้น**
- สินค้าแต่ละร้านอาจไม่เหมือนกัน
- แสดงเฉพาะสินค้าที่มีในสต็อก
- แสดงราคาและจำนวนคงเหลือ

**🔎 กรองและค้นหาสินค้า**
- ค้นหาด้วยชื่อสินค้า
- กรองตามหมวดหมู่:
  - 🍱 อาหารร้อน
  - ❄️ อาหารแช่แข็ง
  - 🧊 อาหารแช่เย็น
  - 🥤 เครื่องดื่ม
  - 🍿 ขนม
  - 💊 ยา

**🛒 เพิ่มสินค้าในตะกร้า**
- แสดงจำนวนสินค้าในตะกร้าที่ปุ่ม
- ปุ่มเพิ่มสินค้าแต่ละรายการ
- สินค้าหมดจะไม่สามารถเพิ่มได้

**ไฟล์:** `src/app/shop/page.tsx`

---

### 3.2 ระบบค้นหาร้าน

#### การทำงาน
1. รับตำแหน่ง (latitude, longitude) จากผู้ใช้
2. ส่งข้อมูลไป Lambda API เพื่อหาร้านใกล้เคียง
3. ได้ข้อมูลร้าน 10 แห่งที่ใกล้ที่สุด
4. คำนวณเส้นทางจริงสำหรับแต่ละร้าน
5. เรียงตามระยะทางเส้นทางจริง
6. ส่งคืนร้านที่ใกล้ที่สุด พร้อมทางเลือกอื่น

#### การจัดการข้อมูล
- แปลงข้อมูลจาก Lambda API ให้เป็นรูปแบบมาตรฐาน
- จัดการกรณีร้าน Lambda timeout
- ถ้าคำนวณเส้นทางไม่ได้ จะใช้ระยะทางเส้นตรง

**ไฟล์:** `src/app/api/stores/nearest/route.ts`

## 4. คอมโพเนนต์ที่สร้างขึ้นใหม่

## 5. การจัดการข้อมูล

### 5.1 Cart Context (ตะกร้าสินค้า)

#### ฟังก์ชันหลัก
- **เพิ่มสินค้า:** เพิ่มสินค้าใหม่หรือเพิ่มจำนวน
- **ลบสินค้า:** ลบสินค้าออกจากตะกร้า

- **ล้างตะกร้า:** ลบสินค้าทั้งหมด
- **เลือกร้าน:** บันทึกร้านที่เลือก

#### การเก็บข้อมูล
- เก็บในหน่วยความจำของเบราว์เซอร์ (Local Storage)
- ข้อมูลยังอยู่แม้ปิดเบราว์เซอร์

## 6. การเชื่อมต่อ API ภายนอก

### 6.1 Lambda Stores API
**เอาไว้ทำอะไร:** หาร้าน 7-11 ใกล้เคียง

**ข้อมูลที่ส่ง:**
- ละติจูด (latitude)
- ลองจิจูด (longitude)
- รัศมี (radius): 5 กม.

**ข้อมูลที่ได้:**
- รายชื่อร้าน 10 แห่งที่ใกล้ที่สุด
- ระยะทาง
- พิกัดร้าน

### 6.2 Lambda Core Route API
**เอาไว้ทำอะไร:** คำนวณเส้นทางจริงจากตำแหน่งผู้ใช้ไปร้าน

**ข้อมูลที่ได้:**
- ระยะทางตามเส้นทาง (กม.)
- เวลาที่ใช้โดยประมาณ (นาที)

## 7. Flow การใช้งาน

### 7.1 สำหรับผู้ใช้ทั่วไป (User)

```
1. เปิดเว็บ → หน้า Login
2. กรอก Email/Password
3. ล็อกอินสำเร็จ → ไปหน้าช็อปสินค้าอัตโนมัติ
4. ระบบขอเข้าถึงตำแหน่ง → กดอนุญาต
5. ระบบแสดงข้อความ "กำลังหา 7-11 ใกล้ฉัน..."
6. พบร้านแล้ว → แสดงข้อมูลร้านด้านบน
7. โหลดสินค้าจากร้านนั้น
8. เลือกดูสินค้าตามหมวดหมู่หรือค้นหา
9. กดเพิ่มสินค้าเข้าตะกร้า
10. กดไปที่ตะกร้าสินค้า
11. ตรวจสอบรายการ
12. กด Checkout
13. ยืนยันการสั่งซื้อ
14. เสร็จสิ้น
```

### 7.2 สำหรับผู้ดูแลระบบ (Admin)

```
1. ล็อกอินสำเร็จ → ไปหน้า Dashboard อัตโนมัติ
2. เปิดเมนูแฮมเบอร์เกอร์
3. เห็นเมนูทั้งหมด:
   - Dashboard (4 หน้า)
   - Shopping (2 หน้า)
   - Admin (2 หน้า)
4. เลือกหน้าที่ต้องการ
5. สามารถช็อปสินค้าได้เหมือนผู้ใช้ทั่วไป
```

- ถ้าเกินเวลา แสดงข้อความแจ้งเตือน

## 12. ปัญหาที่พบและแก้ไขแล้ว

### ปัญหา 1: Lambda API ส่งข้อมูลเป็น String
**สาเหตุ:** Lambda ส่ง JSON ในรูปแบบ string ใน field `body`

**วิธีแก้:**
```typescript
// ตรวจสอบว่าเป็น string หรือไม่ ถ้าใช่ให้แปลงเป็น JSON
if (typeof lambdaResponse.body === 'string') {
  storesData = JSON.parse(lambdaResponse.body);
}
```

### ปัญหา 2: แสดงสินค้าก่อนหาร้าน
**สาเหตุ:** โหลดสินค้าพร้อมกับหาร้าน

**วิธีแก้:**
- เปลี่ยนเป็นหาร้านก่อน → เสร็จแล้วค่อยโหลดสินค้าจากร้านนั้น
- ผู้ใช้เห็นข้อความ "กำลังหา 7-11 ใกล้ฉัน..." ตอนรอ
